# 01 需求

## 背景

企业制度分散在多份文件中，同一事项可能有多份规定，且存在版本更替。员工查询时难以确认
依据的是哪份文件、哪个版本；遇到数值冲突时，也无法判断应采用哪一条。

## 目标

提供可追溯的问答能力：

- 回答附带文档 ID、版本、段落与原文片段；
- 资料冲突时列出双方及各自取值，请求用户确认；
- 无相关资料时说明缺口，不输出无依据的结论。

## 范围

交付命令行问答与离线索引，覆盖制度检索、冲突处理、多轮追问、工具故障四类场景。
语料为 12 篇合成制度，其中 3 篇对报销期限给出不同数值，1 篇为已废止版本。

## 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| F1 | 输入 | 问题与可选对话历史 |
| F2 | 检索 | 按查询返回片段，含 doc_id、版本、章节、摘要 |
| F3 | 读原文 | 读取指定文档或章节全文 |
| F4 | 目录 | 列出全部文档，用于确认资料范围 |
| F5 | 决策 | 根据工具结果选择检索、读原文、回答、追问、弃答 |
| F6 | 校验 | 引用逐字、冲突并列、数量有出处 |
| F7 | 预算 | 步数 10、工具调用 8，超限返回未完成 |

## 输出

| 字段 | 内容 |
|---|---|
| answer | 回答正文；追问时为待确认问题 |
| citations | 文档 ID、版本、段落、原文片段 |
| gaps | 资料缺口 |
| status | 任务状态 |

## 状态机

| 状态 | 进入条件 | 后续 |
|---|---|---|
| 已回答 | 回答通过全部校验 | 终止 |
| 需澄清 | 冲突无优先级，或缺少关键条件 | 等待用户补充 |
| 资料不足 | 两次检索加目录确认后仍无覆盖 | 终止 |
| 失败 | 模型调用失败或工具全部不可用 | 终止 |
| 未完成 | 达到步数或工具上限，或两次校验未通过 | 终止 |

## 验收标准

| 场景 | 输入 | 通过条件 |
|---|---|---|
| 明确答案 | 采购 30 万需要谁审批 | 答分管副总，引用 PRC-001 2.1 |
| 文件冲突 | 报销期限多久 | 列出 FIN-001 的 30 天与 FIN-004 的 15 天，请求确认 |
| 资料外 | 期权行权价 | 两次检索加目录确认后说明缺口 |
| 换用说法 | 差旅费最晚什么时候报 | 命中与"报销期限"相同的文档集合 |
| 上下文追问 | 年假有几天 → 我工作 12 年了 | 第二轮补全省略的"年假" |
| 工具失败 | 注入检索故障 | 重试后作答，不编造 |

## 约束

- 引用须逐字来自本轮证据，且不得仅引用已废止文档。
- 答案中的数量须能在引用中找到。
- 达到预算上限时返回未完成状态并附带已收集证据，不返回空结果。
