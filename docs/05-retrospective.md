# 05 复盘

## 关键决策

| 决策 | 备选 | 收益 | 代价 |
|---|---|---|---|
| 自建决策循环 | LangGraph / LlamaIndex | 每步动作与依据完整落在 trace | 状态、预算、重复调用需自行维护 |
| JSON 动作协议 | 原生 function calling | 换模型不改代码，测试复用同一协议 | 偶发非法 JSON，需修复重试 |
| 规则只输出信号 | 规则直接决定动作 | 动作由模型选择，可解释 | 模型可能忽略信号，需提示词配合 |
| 章节切块 | 定长切块 | 引用可定位到条款 | 长章节占用上下文 |
| 两阶段检索 | 全量 chunk 打分 | 候选规模可控；第一阶段文档摘要向量让纯语义相关文档也能进候选 | 第一阶段阈值截断仍可能漏掉弱相关文档；摘要偏字面 |

## 遇到的问题

**引用校验的边界。** 逐字匹配能拦截编造，无法判断引用与结论是否相关。补充了"数量归属"检查，
仍只能覆盖数值类断言。

**冲突与歧义混用。** 两者触发源不同：前者在检索后出现，后者在问题表述阶段即可判断。
合并为一个追问动作时，"报销期限多久"走不到追问分支。

**规则层越界。** 冲突检测若写成条件分支直接追问，模型便没有选择余地，退化为预设流程。

**接入真实模型后的差异。** mock 只验证链路：证据未写入上下文时 mock 仍能工作，模型则只能反复检索；
动作枚举、参数层级、数量校验都需要按模型输出调整。

## 用时

方案与链路约 1.5 小时；语料、检索、循环与校验约 1.5 小时；测试、运行记录与文档约 40 分钟。
